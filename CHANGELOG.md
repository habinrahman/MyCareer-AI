# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- GitHub Actions CI (backend pytest, frontend lint/test/build, Docker build check)
- Community health files: LICENSE, CONTRIBUTING, SECURITY, CODE_OF_CONDUCT
- Issue and pull request templates
- Dependabot configuration for npm, pip, and GitHub Actions

## [0.1.0] - 2025-04-13

### Added

- AI-powered resume analysis with OpenAI structured outputs
- Career mentorship chat with optional SSE streaming
- Supabase Auth, Postgres (pgvector), and Storage integration
- Next.js 14 frontend with resume intelligence dashboard
- FastAPI async backend with JWT verification
- Docker Compose deployment with Nginx and Let's Encrypt
- Public resume review tool and lead capture flow
- Backend pytest suite and frontend Jest tests
